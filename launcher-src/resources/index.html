    About

    This launcher doesn't sign you in or run Minecraft by itself. It sets up an esp profile in the official Minecraft Launcher, keeps the files up to date, then opens that launcher for you. Your Microsoft login never touches it.

    What it does when you press Play:

    1. Grabs manifest.json from the esp GitHub repo.
    2. Installs the Fabric loader version entry into .minecraft/versions.
    3. Downloads esp and Fabric API into the esp game folder, checking each file's SHA-256.
    4. Adds or updates the esp profile in launcher_profiles.json.
    5. Opens the Minecraft Launcher. Pick the esp profile and hit Play there.

    Not affiliated with Mojang or Microsoft. Using clients like this on servers can get you banned.

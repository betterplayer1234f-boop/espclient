The menu is a web page

Right shift opens it. It's HTML, CSS and JavaScript rendered by Chromium (through MCEF) straight onto a game texture, which is how it gets real springy animations, a proper color picker and smooth fonts.

  • Drag panels around. They snap to a 20 px grid, and holding shift skips the snap.
  • Start typing anywhere to search. Enter toggles the first hit.
  • Right click a module for its settings, middle click to bind it.
  • Configs save on their own a second after you change anything.

Chromium is about 100 MB and downloads in the background the first time you play. Until it's there, you get the native menu in the screenshot. Same layout, drawn with the game's own renderer.

Aim that doesn't snap

KillAura and Scaffold never move your camera. They send a separate rotation to the server, and that rotation has some rules:

  1. 01It speeds up and slows down instead of jumping straight to the target. You set the turn speed range and acceleration.
  2. 02Every step is rounded to what your mouse sensitivity could actually produce.
  3. 03Movement gets corrected so you still walk where your camera faces, even when the server yaw points elsewhere.
  4. 04Hits only go out when the rotation that was really sent lines up with the target.

In third person your head follows that rotation, so you can see what the server sees.

Block animations

Hold right click with a sword, or let KillAura auto block. Pick a style, then nudge X / Y / Z / scale until it sits right.

The launcher

It doesn't replace the Minecraft Launcher. It gets everything ready and then opens it.

  1. 01Reads manifest.json from the GitHub repo to see what's current.
  2. 02Installs the Fabric loader entry into .minecraft/versions.
  3. 03Downloads esp and Fabric API into its own folder (%appdata%\.esp) and checks each SHA-256.
  4. 04Adds an esp profile next to your others, after backing up the profiles file once.
  5. 05Opens the Minecraft Launcher. Pick esp, press Play.
Download esp-launcher.exe

Questions people actually ask

Will I get banned?

On servers with an anticheat, if you turn on combat or movement modules and play like a bot, yes, eventually. esp has no server-specific bypasses. Use it on your own worlds and servers that allow it.

Does it touch my Microsoft account?

No. The launcher never asks you to log in. Signing in happens in the official Minecraft Launcher like always.

Why is it downloading 100 MB the first time?

That's Chromium for the web menu. It downloads once into .esp/esp/mcef. You can play while it downloads, and the native menu fills in until it's done.

Mac or Linux?

The launcher is Windows only for now. The jar works anywhere Fabric does: install Fabric for 1.21.11, then drop esp and Fabric API into your mods folder.

Where are my settings?

.esp/esp/configs/*.json. In chat, .config save name and .config load name switch between them.

Chat commands?

.help lists them all. The ones you'll use most are .t, .bind, .set and .friend.
